# HORUS — Pitching

Este repositório público contém o vídeo de pitching do HORUS para submissões de hackathons.

O vídeo apresenta o problema financeiro e operacional do controle de estoque em clínicas, o fluxo conversacional do HORUS e a proposta de rastreabilidade criptográfica.

O arquivo é um material de apresentação. O código-fonte e as credenciais permanecem no repositório privado do projeto.
